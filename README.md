# Emerging-talent-collaborate

This repository is a collaborative space for sharing **problem set** and **midterm** solutions after the deadlines for the MITx courses:
- [6.001x: Introduction to Computer Science and Programming Using Python]
- [6.002x: Circuits and Electronics]
- 
## 📌 Goal

To **learn from each other's code**, explore **different problem-solving approaches**, and build **stronger coding habits** by reviewing and reflecting on solutions post-deadline.

## 📁 Structure

- `6.001/`: Problem sets and midterm solutions for the 6.001 course.
- `6.002/`: Problem sets and midterm solutions for the 6.002 course.

Each problem set or exam folder contains named solution files by students.

## 🔐 Rules

- **Do NOT upload solutions before official deadlines.**
- Respect everyone's work and always give credit when referencing someone else's solution.
